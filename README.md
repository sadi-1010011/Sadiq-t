# Muhammed Sadiq T — Portfolio

Personal developer portfolio built with vanilla HTML, CSS, and JavaScript. No frameworks, no dependencies — just clean, fast, and responsive code.

**Live site:** [sadiqt.com](https://sadiqt.com)

---

## Overview

A single-page portfolio showcasing my work as a MERN Stack Developer, including experience, projects, skills, and contact info.

**Sections:**
- Hero
- About
- Experience
- Skills
- Projects
- Education
- Contact

---

## Project Structure

```
portfolio-sadiq/
├── index.html      # Main HTML — all sections and content
├── index.css       # All styles, design tokens, and responsive layout
├── script.js       # Scroll animations, nav toggle, active link tracking
├── profile.png     # Profile photo
└── cv.pdf          # Downloadable CV (linked in mobile nav and contact)
```

---

## Features

- Fully responsive — mobile-first layout with a slide-in hamburger menu
- Scroll-reveal animations
- Active nav link tracking on scroll
- CV download button in mobile drawer
- No build step — open `index.html` directly in a browser

---

## Running Locally

No setup needed. Just open the file:

```bash
open index.html
```

Or serve with any static file server:

```bash
npx serve .
```
